# Inventory Reservation System

A concurrency-safe inventory reservation system built with Next.js, Prisma, PostgreSQL, and TypeScript.

## Problem Statement

This project solves the inventory reservation problem for e-commerce systems where multiple users may attempt to purchase the same product simultaneously.

The system temporarily reserves stock during checkout and prevents overselling using transactional database operations.

## Features

- Multi-warehouse inventory management
- Temporary stock reservations
- Reservation expiry handling
- Concurrency-safe reservation logic
- Live countdown timer
- Reservation confirmation and release flow

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Prisma ORM
- Tailwind CSS
